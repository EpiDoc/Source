Commentary

2026-08-21

The div with type="commentary" is intended to contain commentary written in prose, of any kind, concerning a text or its support, the dating criteria of either, specific parts of the text, external references, named persons and entities mentioned, etc. These commentaries can be divided into several paragraphs, p, or blocks, ab or <div type="textpart">. In general, running prose such as this will require less inline markup than most sections of the EpiDoc file, but some features may benefit from specific encoding, a few of which are discussed below.

Line-by-line commentary

As well as running prose commentary, some may include line-by-line commentary, in which the editors record epigraphic, philological, prosopographical or historical observations or analysis of specific words in the text. These sections may be encoded, depending on display preference and the length of each entry, either as a series of paragraphs, p, or as a list with one item for each entry. Each entry would generally begin with a [sometimes section and] line reference to the part of the text the commentry addresses; this may be as simple as plain text in the body of the element (<p>l. 6: …</p>), but a more explicit encoding such as a canonical reference in n (<p n="6">) might be desirable; the most unambiguous of all would be to use internal pointers to the lines in the text using the corresp attribute (the line in the text to which this line of commentary corresponds), e.g. <p corresp="#sect1-line6">, assuming that each lb in the text has a unique xml:id that can be pointed to in this way.

Foreign-language sections

Words, expressions, or passages written in another language may be encoded using the foreign element, whose xml:lang attribute defines the language used (see Multi-Language Texts).

<div type="commentary">
 <p>About the rare word <foreign xml:lang="grc">καλυβός</foreign>, see commentary at <ref type="inscription">GVCyr005</ref>.</p>
</div>
(GVCyr: gvcyr008)

Note that in a language well-supported by Unicode such as Ancient Greek, the use of foreign is only necessary if some processing or encoding of the quoted words is anticipated.

Quotes

Quotes from other references can be encoded using the quote element. The corresponding reference can be indicated with a bibl element pointing to the bibliographic reference, placed immediately after (see Encoding the Bibliography).

Cross-references

The ref element can be used to encode internal cross-references (to a part of the document) or external ones (to another document). Its target attribute contains either the value of the xml:id attribute of the linked element preceded by # (internal reference), or the URI or path to another document, optionally supplemented with the value of the xml:id attribute of the linked element (external reference).

<div type="commentary">
 <ab>This is not the only instance of an unfinished inscription: see <ref target="C0128.xml">C. 128</ref>.</ab>
</div>
(Source)

Bibliographic references

Bibliographic references cited in commentaries can be encoded with the bibl element (see Encoding the Bibliography).

<div type="commentary">
 <p>This well made epigram develops the theme of malediction by playing on the name of the deceased woman 'Arata', which etymologically means 'accursed', directly through the use of <foreign xml:lang="grc">ἀρά</foreign> and indirectly through two puns based on the assonance with the interrogative particle <foreign xml:lang="grc">ἇρα</foreign> and with <foreign xml:lang="grc">ἀρετά</foreign> 'virtue'. More at <bibl>
   <ptr target="#cdl2018"/>
  </bibl>.</p>
</div>
(Source)
